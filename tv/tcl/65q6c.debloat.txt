# TCL 65Q6C / T65Q6C Specific Debloat Package List (QM6 / C6K Regional Equivalent)
# Target Device: TCL 65Q6C (BeyondTV / Android 12)
#
# Note: Universal Google TV bloatware is in tv/common/common.debloat.txt and applied automatically.
#
# Safe to disable with:
#   adb shell pm disable-user --user 0 <package>
#
# IMPORTANT SAFETY FOR TCL:
# Do NOT disable:
#   - com.tcl.tv              (Live TV player)
#   - com.tcl.tvinput         (HDMI and tuner inputs)
#   - com.tcl.dashboard       (Quick settings & picture mode overlay)
#   - com.tcl.providers.config(CRITICAL: disabling this drops Wi-Fi on TCL!)
#   - com.tcl.initsetup       (System boot requirements)
#   - com.tcl.autopair        (Bluetooth remote control pairing)
