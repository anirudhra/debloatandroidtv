# TCL Q6C / QM6 Specific Debloat Package List (QM6 / C6K Regional Equivalent)
# Target Device: TCL Q6C / QM6 (BeyondTV / Android 12)
#
# Note: Universal Google TV bloatware is in tv/common/common.debloat.txt and applied automatically.
#
# Safe to disable with:
#   adb shell pm disable-user --user 0 <package>
#
# IMPORTANT SAFETY FOR TCL (G08 / BeyondTV / MediaTek):
# Do NOT disable:
#   - com.tcl.tv                           (Live TV & HDMI player)
#   - com.tcl.tvinput                      (HDMI and tuner input services)
#   - com.tcl.suspension                   (Quick Panel source menu on the Input key)
#   - com.tcl.dashboard                    (Quick settings & picture mode overlay)
#   - com.tcl.providers.config             (CRITICAL: disabling this drops Wi-Fi on TCL!)
#   - com.tcl.initsetup                    (CRITICAL: required for Wi-Fi & boot stability)
#   - com.tcl.factory.view                 (CRITICAL: disabling drops Wi-Fi on AU14/AU16 firmware)
#   - com.tcl.autopair                     (Bluetooth remote control pairing across battery changes)
#   - com.tcl.inputmethod.international    (Default keyboard IME unless Gboard is set first)
#
# Note on com.tcl.ttvs & com.tcl.interactive:
# On some G08 Q6C/Q7C builds, com.tcl.ttvs hosts SystemUpdateActivity (OTA firmware updates)
# and com.tcl.interactive is bound by com.tcl.tv for source overlays (disabling both with
# pm disable-user can cause a 10 Hz NPE logcat storm on AU02/AS35 firmware). Using `lockdown:`
# starves their background CPU/telemetry while keeping OTA and source bindings intact:

# --- TCL Background Lockdown (Starve Background Telemetry, Preserve OTA & Source Overlays) ---
lockdown:com.tcl.ttvs                  # Samba TV ACR viewing tracking, TCL "BI" analytics, Alexa core
lockdown:com.tcl.interactive           # TCL TIAS interactive ad/overlay service
